# Flash-Card-Game
A small Tkinter-based flashcard app to practice French — pick a card, guess the translation, then tap the ✅ if you knew it or ❌ if you didn’t. Known words are removed from the study set and progress is saved, so you can pick up where you left off.

Features

Auto-flips card after 3 seconds to show translation.

✅ Right button: mark a word as known (removed from future practice).

❌ Wrong button: keep the word in the pool to practice again.

Progress saved to words_to_learn.csv so learning persists across runs.
